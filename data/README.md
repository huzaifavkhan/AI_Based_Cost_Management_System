# Data Directory

This directory contains reference CSVs, model weights, and training datasets.
Large files are **not tracked by git** and must be downloaded separately.

---

## What is included in the repository

| File | Description |
|------|-------------|
| `purchase_orders.csv` | Reference PO data for three-way matching |
| `goods_receipts.csv` | Reference GR data for three-way matching |
| `historical_invoices.csv` | Historical invoice records for anomaly detection baseline |
| `invoices.csv` | Sample processed invoices |
| `contracts.csv` | Contract reference data |
| `layoutlm_invoice/config.json` | LayoutLMv3 model architecture config |
| `layoutlm_invoice/tokenizer*.json` | LayoutLMv3 tokenizer files |
| `layoutlm_lora/adapter_config.json` | LoRA adapter configuration |
| `layoutlm_lora/adapter_model.safetensors` | FL-trained LoRA adapter weights (~3.4 MB) |
| `layoutlm_lora/fl_lora_metadata.json` | Federated training run metadata |
| `fl_model/fl_model.pkl` | Federated anomaly detection model |
| `fl_model/fl_scaler.pkl` | Feature scaler for the FL model |
| `fl_model/fl_metadata.json` | FL training metadata |

## Model Weights (not in repo — download required)

Two large model files (~480 MB each) must be downloaded and placed manually:

### 1. Base LayoutLMv3 Fine-tuned Model
**Path:** `data/layoutlm_invoice/model.safetensors`

This is the fine-tuned LayoutLMv3 invoice extraction model trained on the CORD + synthetic dataset.

> Download link: *(upload to HuggingFace Hub or Google Drive and paste link here)*

**To place:**
```
data/
  layoutlm_invoice/
    model.safetensors   ← place here
    config.json         (already in repo)
    tokenizer.json      (already in repo)
```

### 2. FL-LoRA Merged Model
**Path:** `data/layoutlm_lora_merged/model.safetensors`

This is the federated learning LoRA-merged model (base + adapter weights merged).

> Download link: *(upload to HuggingFace Hub or Google Drive and paste link here)*

**To place:**
```
data/
  layoutlm_lora_merged/
    model.safetensors   ← place here
    config.json         (already in repo)
    tokenizer.json      (already in repo)
```

## Training Datasets (not in repo)

| Directory | Contents | Size |
|-----------|----------|------|
| `data/real_invoices/` | Real invoice images with annotations (~9,600 files) | Large |
| `data/synthetic_receipts/` | Synthetically generated receipt images (~4,500 files) | Large |
| `data/sample_invoices/` | Small sample set for quick testing (~30 files) | Small |

These are used only for fine-tuning scripts in `scripts/`. The system works without them for inference.

> If you need the training datasets, contact the project authors or use the scripts in `scripts/` to regenerate synthetic data:
> ```bash
> python scripts/generate_synthetic_data.py
> python scripts/generate_receipt_images.py
> ```
